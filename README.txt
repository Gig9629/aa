AR ปลามังกร (AR.js + Hiro marker)

ไฟล์:
- index.html       หน้า AR พร้อมปลามังกร 3D และปุ่มปรับความเร็ว
- hiro.patt        ไฟล์ pattern marker มาตรฐาน Hiro ของ AR.js

วิธีใช้งาน:
1) วาง index.html และ hiro.patt ไว้โฟลเดอร์เดียวกัน
2) เปิดด้วยเว็บเซิร์ฟเวอร์ เช่น `python -m http.server 8000`
3) เปิด http://localhost:8000/ ด้วย Chrome/Edge บนมือถือหรือคอมที่มีกล้อง
4) อนุญาตการใช้กล้อง แล้วส่องไปที่ Hiro marker
5) ปุ่ม ช้า / ปกติ / เร็ว / เร็วมาก จะเปลี่ยนความเร็วการว่ายและการแกว่งหาง

หมายเหตุ: การเปิด index.html ด้วย file:// โดยตรงอาจไม่สามารถใช้กล้องได้ในบางเบราว์เซอร์ ควรใช้ localhost หรือ HTTPS
